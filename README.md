# NGKR-circular-loop


[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

## Overview

This repository provides the code to compute the collapse of a circular global axion string loop in the Nambu--Goto--Kalb--Ramond (NGKR) effective theory.


## Installation

Clone the repository:
```bash
git clone  https://github.com/mathieukaltschmidt/NGKR-circular-loop.git
cd NGKR-circular-loop
```

## Repository Structure
```
NGKR-circular-loop/
├── NGKR_loop.py/          # Core module for running the circular loop collapse using the NGKR EFT
├── run_NGKR.ipynb         # Jupyter notebook explaining the basic usage of the code
```

## Usage

An example notebook explaining the basic usage is:
```bash
run_NGKR.ipynb
```
